## Alcance previsto

Cliente móvil para registro financiero, presupuestos, educación y dispositivos,
según las capacidades que se implementen. El diagrama del PDF propone Flutter
para iOS/Android; todavía no hay un proyecto Flutter ni configuración de compilación.

Los contratos REST de `back` ofrecen el punto inicial de integración. La
identidad real y los demás servicios siguen pendientes. La adaptación del
panel web a pantallas pequeñas no constituye una aplicación móvil nativa.

No hay APK, código móvil ni publicación en tiendas. Este repositorio tiene
su propio historial Git y está preparado para incorporar el proyecto futuro.
